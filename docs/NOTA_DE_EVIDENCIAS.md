# Registro de evidencias que debe completar la estudiante

No marcar como cumplido hasta contar con soporte real:

1. Captura de la página inicial ejecutándose localmente.
2. Captura del detalle de un centro con datos ficticios claramente rotulados o datos oficiales ya validados.
3. Captura del panel administrativo con sesión iniciada.
4. Capturas de creación/edición/eliminación de centro, servicio, horario y requisito.
5. Salida real de `pytest -q` y fecha/versión del código.
6. URL del repositorio Git remoto, revisada desde una ventana privada para confirmar acceso.
7. Acta o registro de revisión de información con la fuente institucional consultada.
8. Formatos de usabilidad y cuestionarios SUS diligenciados voluntariamente por participantes reales, con consentimiento.

No incluir nombres, cédulas, teléfonos personales ni información clínica de participantes en el informe. Usar códigos U01, U02, etc. Los datos de salud de la comunidad no deben incorporarse a esta aplicación.
